## 🚀 Overview | Descripción

**EN 🇺🇸**  
**Dzulclass** is a web-based application designed to manage clothing items, inventory, and product data.

It demonstrates backend development using Laravel, focusing on structured data handling and real-world business logic.

**ES 🇲🇽**  
**Dzulclass** es una aplicación web diseñada para gestionar ropa, inventario y productos.

Demuestra el desarrollo backend con Laravel, enfocado en manejo de datos y lógica de negocio.

## 🚀 Getting Started | Instalación

```bash
git clone https://github.com/Alucarduwu/Dzulclass.git
cd Dzulclass
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```
